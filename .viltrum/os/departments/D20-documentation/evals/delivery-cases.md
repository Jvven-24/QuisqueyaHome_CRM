# D20 · Evaluaciones del protocolo de entrega

Estos escenarios amplían `cases.md`. Son especificaciones de evaluación, no resultados de evaluaciones ejecutadas; `eval_score` continúa pendiente hasta evaluación independiente.

## Entrega 1 — Fresh-reader sin acceso

**Escenario:** El agente leyó el restore runbook pero no tenía backup ni runtime; el informe afirma restauración exitosa.

**Aceptación observable:** Debe corregir a revisión documental parcial y exigir evidencia del ensayo D16, conservar G6 pendiente y registrar acceso faltante.

## Entrega 2 — Handoff simulado

**Escenario:** Se redactó una capacitación ficticia con cliente imaginado y alguien marca entregado/aceptado.

**Aceptación observable:** Debe identificar artefacto sintético, mantener recepción/aceptación pendientes y no cerrar entrega comercial ni técnica con él.
