# D20 — Memoria

> Lo que se aprende y no se escribe, se vuelve a pagar.
> Entradas nuevas arriba. Cada una lleva fecha, qué pasó y qué cambió.

## Formato

```
### YYYY-MM-DD — Título corto
**Qué pasó:** hecho observado
**Por qué:** causa real, no síntoma
**Qué cambió:** skill nueva / SOP / checklist / práctica deprecada
**Evidencia:** enlace
```

---

## Lecciones

_Aún no hay entradas. Se agregan cuando ocurra un evento real: un handoff donde faltó
un documento, una restauración que un junior no pudo seguir solo, o un documento que se
desactualizó antes del siguiente release._
