# D17 — Memoria

> Lo que se aprende y no se escribe, se vuelve a pagar.
> Entradas nuevas arriba. Cada una lleva fecha, qué pasó y qué cambió.

## Formato

```
### YYYY-MM-DD — Título corto
**Qué pasó:** hecho observado
**Por qué:** causa real, no síntoma
**Qué cambió:** skill nueva / SOP / checklist / práctica deprecada
**Evidencia:** enlace
```

---

## Lecciones

_Aún no hay entradas. Se agregan cuando ocurra un evento real: un incidente cerrado con
postmortem, una alerta silenciosa que debió sonar y no sonó, o un SLO que resultó estar
mal calibrado contra el comportamiento real del sistema._
