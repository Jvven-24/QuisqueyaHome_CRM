# pxil-experience-contract
Skill to generate the Experience Contract.

## Instructions
Generate an Experience Contract based on user flows and capabilities. Detail the following components for each interaction:
- **Screen**: The user interface context.
- **State**: The current state of the application/UI.
- **Event**: The user action or system trigger.
- **Feedback**: The system response or UI feedback resulting from the event.
Ensure comprehensive coverage of the user journey. Output in PXIL format.
