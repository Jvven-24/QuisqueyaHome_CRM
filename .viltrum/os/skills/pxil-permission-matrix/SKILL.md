# pxil-permission-matrix
Skill to generate the RBAC/ABAC permission matrix.

## Instructions
Analyze the module map and data model to define the required access controls. Generate a comprehensive permission matrix outlining Role-Based Access Control (RBAC) and/or Attribute-Based Access Control (ABAC). Specify permissions for each role across all entities and endpoints. Output in PXIL format.
