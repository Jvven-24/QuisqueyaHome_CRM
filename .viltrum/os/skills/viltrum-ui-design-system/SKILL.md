# D05 · UI y sistema de diseño

Lee [protocolo de entrega](../../departments/D05-ui-design-system/sops/delivery.md) y [contrato del perfil](../../departments/D05-ui-design-system/AGENTS.md). Resuelve enlaces desde la skill del repositorio o snapshot, no el cwd del consumidor.

Inspecciona sistema y biblioteca existentes; recibe estructura D04 y estados D06. Entrega fuente de tokens, variantes de componentes, composición responsive y prototipo enlazados a requisitos. Investiga componentes existentes antes de crear; una biblioteca externa necesita compatibilidad/licencia, decisión D21 y revisión de riesgo según D12.

D07 revisa y D09 recibe especificación cuando los gates permiten construir. Figma/MCP y CLI de catálogo requieren acceso real; no prometas sincronización por tener un nombre de skill. Evidencia de diseño y evidencia de interfaz ejecutada se registran separadas. Un concepto previo a C1 no inicia frontend de producto.
