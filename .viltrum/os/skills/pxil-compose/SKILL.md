# Skill: pxil-compose

## Description
Generate the final Screen Recipe before implementation.

## Instructions
1. Review the requirements and the selected components vetted by the Visual Inspector.
2. Determine the layout structure to compose these components into a cohesive screen.
3. Document the component hierarchy.
4. Specify any required layout containers (e.g., flex, grid) and spacing (padding, margin, gap).
5. Output a structured Screen Recipe containing the layout plan, component list, and visual override instructions.
