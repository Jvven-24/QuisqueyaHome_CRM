# PXIL para los perfiles Viltrum

Snapshot metodológico importado desde VILTRUM DESING por solicitud del propietario.
Ver `provenance.json` para archivos y hashes; las copias originales están en `reference/`.
Las skills activables se encuentran en `skills/pxil-*` y el procedimiento integrador en
`skills/viltrum-pxil-design/SKILL.md`, relativos a la raíz del SDK.

El catálogo `registry/design-resources.json` conecta nueve departamentos. Los prompts
del runtime cargan sus `supporting_skills` y el dashboard permite inspeccionarlas.
Es una integración de contratos y contexto; no instala ni ejecuta automáticamente las
herramientas de terceros. Tampoco modifica gates, aceptación comercial o permisos.

Ver `docs/architecture/HANDOFF-PXIL-21ST.md` para arquitectura, límites y comandos.
